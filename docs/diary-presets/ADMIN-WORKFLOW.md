# 预设手帐后台业务流程与页面规范

日期：2026-10-16。

## 系列不显示的原因

公共 axios 实例的响应拦截器已经返回 payload.data 或 response.data。旧预设页再次访问 `.data`，把正确的系列数组读成 undefined，导致只有“新增系列”按钮而无条目。已统一改为读取拦截器返回的数据，加载成功后默认选择首个系列。未修改舟山素材或重新发布版本。

## 信息架构

入口仍在当前后台“预设手帐”。左侧系列目录；右侧上方手帐表格；选中手帐后下方显示工作区。工作区分为页面管理、版本记录、上传任务。初次进入展示加载态，失败展示错误和刷新入口，无数据有空状态。

## 系列管理

新增/编辑用 Ant Design 表单弹窗：名称、唯一 slug、排序、启用。点击系列过滤手帐列表；非空系列禁止删除；停用可以保留内容但从客户端目录隐藏。系列排序通过数值修改，数值小者先显示。

## 手帐管理

手帐表格显示封面缩略图、名称、简介、页数、状态、排序、管理入口，支持名称搜索和前端分页。新增/编辑表单包含名称、系列、简介、排序和启用状态，编辑所属系列可移动手帐。当前工作区显示工作修订号、未保存更改标记；下架/恢复展示为可逆操作，已有用户作品不受影响。

## 页面管理

按顺序显示缩略图、页标题、序号和封面标记。点击预览取 OSS 大图。支持拖动、前移/后移、改页标题、设置封面、删除；至少保留一页。删除当前封面自动选剩余首个页面，管理员可调整后保存。界面中的修改先停留在内存，切换手帐或路由前提醒。

“保存草稿”写入服务端草稿，不改变客户端已发布版本；“保存并发布”先保存调整，再创建不可变版本。若保存成功但发布失败，草稿保留，错误提示允许再次发布。工作修订号用于乐观锁，旧编辑返回 409，要求刷新。

## 添加素材

选择“单页资源包”及插入锚点，或“整本资源包”，上传完整 .diarypreset.zip。单页包只能含一页和完整依赖；整本上传替换工作草稿。文件由浏览器 STS 分片直传 OSS，界面显示进度、暂停/继续。刷新后重新选择同一文件恢复 checkpoint；不持久保存 STS 密钥。上传期间需先完成或暂停，再切换对象。

上传完成后显示 queued/processing/published/failed/conflict。云处理器校验成功直接发布，无人工审核。上传任务页可查看最近 100 项、失败详情并重试；重试携带当前草稿修订和插入锚点。任务完整 ZIP 不经过低带宽服务器。独立云执行器未上线时，queued 会持续等待，界面明确提示依赖。

## 版本管理

列出版本号和发布时间。回滚需二次确认，使用历史快照创建新的发布版本以保留发布轨迹。回滚不会改动已经被客户端固定版本的下载计划，也不删除用户作品。

## 当前验证范围

前端 TypeScript 检查及生产构建；后端权限、固定版本、下载计划归属、局部依赖、修订冲突、系列/上传列表契约测试；本机舟山数据库及认证 HTTP 链路。浏览器需现有账号登录后查看，未修改任何密码。生产环境本次未部署。
