# 字体同步到服务（共享 OSS）

日期：2026-10-28。字体同步核心代码已实现并通过自动化验证，真实跨环境同步尚未执行；需先部署两端代码及迁移、重启任务服务。

## 使用方法

后台“内容资源 → 字体管理”，已发布并上架字体的操作列出现“同步到生产”。操作顺序与贴纸一致：预检 → 查看字面差异、生产版本、OSS 检查结果与价格处理说明 → 确认同步并发布 → 查看已同步状态。弹窗支持历史任务、重新预检和结果未知时重新核实。

仅同步已发布版本。未发布草稿不会被带到生产，目标有草稿／人工修改／下架状态时阻止覆盖。同步保留字体 UUID、字面 ID、资产 UUID、原始 OSS object_key 和来源版本号；客户端已有字体引用不会因重新编号改变。

## OSS 与带宽

双方必须使用相同 ALIYUN_OSS_BUCKET、ALIYUN_OSS_ENDPOINT 和 FONT_OSS_PREFIX。能力检查、预检与导入均核对共享存储。字体 prefix 是共享资源命名空间，不能一端 development、一端 production；配置变更前核对现有资源 key，不能只改字符串使旧资源失效。

同步 API 仅传 JSON 清单，生产通过 OSS HEAD 检查对象存在、大小、MIME；不 GET／PUT 字体或小样，不 COPY 搬运对象。可信字体解析结果来自已发布来源资源，跨环境服务身份由 HMAC 验证；不是重新把浏览器未验证文件变成可信资产。

## 配置与部署

沿用贴纸已建立的 MATERIAL_SYNC_* 配置和服务凭据，不另在浏览器配置生产地址或密钥。传输前缀为 `/api/v1/font-sync/`，独立于贴纸 `/api/v1/material-sync/`。HMAC 包含完整路径和请求摘要，复用全局 nonce 防重放记录。

1. 两端备份后应用字体迁移至 `0003_alter_fontfamily_options_fontsynctask_fontsyncslot_and_more`；正常 `manage.py migrate` 自动包含依赖。
2. 按现有方式运行 RBAC 初始化，给操作员字体同步及字体发布权限。同步 API 按 Django 权限检查，与贴纸同步一致；普通编辑权不自动授予跨环境发布权。
3. 来源启用 MATERIAL_SYNC_SOURCE_ENABLED；目标仅 production 启用 MATERIAL_SYNC_RECEIVER_ENABLED；双方沿用既有 key ID、secret 和 accepted keys 的绑定规则。
4. 两端重启 Celery worker，须注册 `font_library.tasks.run_sync_task`；beat 增加每 30 秒恢复扫描 `font_library.tasks.recover_sync_tasks`。元数据任务可运行在现有业务服务任务环境，不读取文件正文。
5. 生产反代放行 font-sync 路径；API 使用固定允许的生产 HTTPS 地址，不跟随重定向。
6. `FONT_PROCESSOR_TOKEN` 是上传字体的独立解析凭据，与生产同步 HMAC 凭据用途不同，不互相替代。

## 收费规则

生产已有字体策略时原样保留，不覆盖价格、会员范围、用户、订单和领取记录。首次导入且生产没有策略时，预检展示来源策略，确认后在同一事务建立初始商品策略。收费／Pro 模式需通过生产销售开关和授权范围校验，不能偷偷降级为免费。生产已有未发布价格配置时要求先在生产处理，避免覆盖运营意图。

价格后续调整继续在生产收费中心进行；同步不是跨环境迁移钱包和用户权益工具。

## 可靠性与冲突

- 源／目标各有持久任务，目标同步槽、租约、幂等键与同步映射独立于贴纸表。
- 确认前检查来源发布版本；提交前重新检查目标指纹（包括草稿、资产和价格修订）。
- 生产资源版本沿用来源版本，新内容不得覆盖低于或等于生产的既有版本；同内容更高版本也建立相应版本，保持引用语义。
- 内容一致不重复发布；提交结果丢失先按业务键查询，已提交任务只做核实，禁止重复导入／重复创建价格策略。
- 相同资产身份的不同元数据、同 PostScript 名称不同字体文件、缺文件、私有目录及错误存储环境均阻止同步。

## 2026-10-28 本地交付目录兼容修复

霞鹜文楷已发布资源由本地交付工具存入 `FONT_OSS_PREFIX/deliveries/{family_uuid}/{sha256前16位}/{文件路径}`，原同步协议只允许 candidates／blobs／media／licenses，导致来源预检直接报 INVALID_SNAPSHOT。现增加 deliveries 路径支持，同时强制字体 UUID 与清单一致、目录摘要与资源摘要一致，仍拒绝越目录、其他字体及错误摘要。文件不搬迁、不重新上传，原作品引用不变。本机真实已发布霞鹜文楷的四项资源清单已通过修复后的校验，未自动执行生产发布。来源 API／worker 与生产接收端都需要加载此修复代码。
