# 后台销售开关

入口：收费与权限页面顶部「销售开关」，仅超级管理员可读取和修改。显示当前环境；生产开关需在生产后台设置。本地设置不随内容同步到生产。

两个开关：

- 钻石兑换：控制正式环境的钻石兑换、新钻石价格策略发布、模板及字体首发同步预检。充值与数字定制扣款仍由原独立开关控制。
- 会员销售：控制会员服务返回的 sales_enabled、新 Pro 价格策略发布、模板及字体首次同步预检。关闭不撤销已有权益，符合原逻辑。Apple 验证的沙盒测试覆盖保持原行为。

未保存运行时设置时沿用既有环境变量。第一次保存后以当前环境数据库 SalesControl 单行记录为准，API、Celery 每次读取生效，无需重启或编辑 .env。没有自动开启开关。关闭数据库开关可覆盖环境变量 true；SalesControl 不包含在内容同步清单中。

PATCH /api/v1/billing/manage/sales-settings/ 要求 expected_revision、两个布尔值和修改原因；保存前页面确认影响和当前环境。事务行锁及 revision 防止覆盖他人修改；BillingAudit 保存前后状态、原因、环境和操作者。GET 不创建记录。非超级用户返回 403。

billing.0012_salescontrol 为新增迁移。105 项后端测试和 1 项页面交互测试通过，TypeScript/生产构建通过，包含权限、审计、并发版本检查、环境变量回退、关闭覆盖和沙盒行为。模板/字体销售拦截已有回归一并通过。

大理模板仍保留原 100 钻石策略。需要在生产后台开放钻石兑换后，再在本地批次重试失败项。若预检错误代码仍为旧回执，应重新预检；若本地版本已变，需新建同步清单。操作开关不自动购买、不自动重试或导入任何资源。

已发布到生产版本 `20261030_095320_48650_16193`，billing.0012 已应用，标准发布检查及 HTTPS 健康检查通过。本地真实 HTTP GET 返回 200。直接核对生产开关：diamond=false、membership=false、revision=0，未创建运行时覆盖记录；没有打开任何销售功能或自动重试同步。
