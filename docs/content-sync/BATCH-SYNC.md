# 统一批量同步到生产

后台入口：内容资源 → 批量同步到生产（`/content/sync`），仅启用发送环境的超级管理员可执行。生产不启用发送。页面支持选择模板、贴纸、背景、字体、自动包含依赖、固定清单确认、批次历史、后台执行、关闭页面后恢复查询及仅重试失败项。

## 执行和一致性

清单冻结本地发布快照、版本、OSS key、摘要及首发价格策略，有效期 30 分钟。用户确认清单后授权批次逐项完成生产预检与发布；该确认不等同于已完成远端预检。每项预检失败均保留原因，不强制覆盖冲突。源内容在确认及远端提交前重新比较；源已变化时必须新建批次。

批次按依赖顺序串行调度既有 HMAC 接口。整本带出固定版本的配套贴纸、背景并原子建立 `TemplateLibraryBinding` 和 `TemplateMaterialLink`、页面及搜索索引。选择配套包会自动包含其所属整本；未绑定到整本当前发布版的包不允许选择。空素材包不可选择，解除空包绑定需通过模板发布。独立素材支持 sticker/background 两种类型。现有独立素材协议保持既有版本号映射行为，模板和字体保留来源版本号。

字体依赖使用 manifest.requiredFonts 中明确的字体 UUID、版本和字面 ID；自动加入云字体任务。当前只支持引用云字体的当前发布版本，其他版本必须先明确处理，不能猜测名称或静默替换。系统字体与客户端内置 `handwriting.lxgw.wenkai` v1.522 不需要云字体任务。云字体引用仍由模板原始 manifest 保存，客户端按该引用加载。其他未知字体会阻断清单。

收费附赠包必须为独立贴纸包，先同步再检查其生产价格策略；不自动迁移用户或权益记录。已有生产价格保留，首次收费策略遵循销售开关，缺失价格配置时预检提示，不能默认为免费。

批次记录存于 backoffice.ContentSyncBatch，子项沿用三类同步任务表。worker/beat 接管执行及 30 秒恢复扫描。子任务保留幂等标识和生产回执；结果未知的重试继续核对旧任务，不能生成第二个导入。批次内成功项保留，失败依赖阻断后续整本，其余项继续。配套包列表通过成功整本回执核对固定素材版本展示“已随整本同步”。

同一套 OSS 桶、endpoint 和前缀必须一致。仅同步元数据，同步预检及导入均不请求 OSS 检查对象，不复制、上传、下载或删除资源文件。

## 批次历史查询修复（2026-10-30）

本地页面资源列表可加载，但历史接口 GET batches/ 报 MySQL 1038 `Out of sort memory`。原因是按 created_at 排序时 SELECT 同时包含大体积 entries JSON，MySQL filesort 携带完整快照，默认 sort_buffer_size 不足。

改为先按 created_at DESC、id DESC 查询最近 20 个批次 ID，再按主键 in_bulk 获取内容并恢复顺序；增加 content_sync_recent 复合索引（backoffice.0006）。不调整数据库全局内存参数，不修改或删除批次内容。

验证：6 项批次测试通过，新增测试检查历史排序 SQL 不包含 entries JSON；在本地真实 MySQL 将会话排序缓冲区设为 32768 字节，包含 103 项大清单的历史查询返回 200。重启本地 API 后，通过真实 HTTP 认证请求 catalog/ 和 batches/ 均返回 200。
