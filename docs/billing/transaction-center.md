# 后台交易中心

实施日期：2026-10-28。入口：`/billing/transactions`。

## 日常使用

- 默认正式环境；测试充值请切换「沙盒环境」。所有列表、金额汇总、用户资产与异常查询均按项目和环境隔离。
- 「钻石充值」分别显示支付状态、到账状态、应到账及确认数量。渠道缺失历史金额时显示待确认。
- 「会员订阅」保留每次购买、续费对应交易。取消续订、退款、到期是不同状态，会员资产的有效期和核验时间单独展示。
- 「钻石消费」查询内容兑换与履约状态；「定制付款」查询定制单、套餐、付钻状态。
- 「用户资产」展示 RevenueCat 余额快照、同步时间、会员有效期、核验时间及内容拥有权。用户详情页也有「查看资产与交易」入口。
- 「收款动态」展示已接收的用户渠道事件；「异常提醒」展示对账异常。超过 5 分钟未确认到账的充值在页首提示。
- 页面打开时可每 30 秒刷新，支持关闭。后台标签页隐藏、详情打开或已有请求运行时暂停自动刷新。
- 支持用户名、用户 ID、RevenueCat App User ID、记录日期、交易状态和分页筛选。日期指后台记录日期；详情同时展示渠道购买时间。
- 实物订单继续使用原有支付管理、印制订单与退款流程。

## 数据与金额

`StorePayment` 是只读报表投影，不参与发钻和权益发放。接收已认证并处理通过的 RevenueCat 回调后，按项目、App、环境、商店和渠道交易号合并记录；同一笔交易的购买、发钻和退款事件保留关联。

历史金额读取购买事件的 `price_in_purchased_currency` 和 `currency`，保存 Decimal；不使用当前商品价格，不把 USD `price` 字段当成本币价格。未知金额保持 null，免费试用的 0 保持 0。

汇总按币种分别计算确认购买金额，排除已确认退款；不是财务结算单，不计算税费、Apple 佣金或银行到账金额。钻石兑换与定制付钻不会重复计入现金收入。

订阅 `CANCELLATION` 中 `UNSUBSCRIBE` 表示关闭续费；`CUSTOMER_SUPPORT` 按渠道退款事件处理。取消续费不直接清空会员有效期。退款状态按事件时间更新，后到的旧购买或旧退款不会覆盖较新的退款/退款撤销状态。

先到发钻事件时显示付款待确认；收到购买事件后补充支付与金额。同步资产仅调用 RevenueCat 查询余额及会员快照，不补钻、不重放付款、不将未知订单直接确认成功。同步操作记录审计。

## 权限与部署

- `billing.view_transactions`：查看交易、客户资产、关联事件和 RevenueCat 客户链接。
- `billing.sync_transactions`：查询并更新客户资产快照。
- 权限随迁移登记，普通运营角色须通过现有权限管理分配。未自动扩展普通账号权限。超级管理员沿用既有规则。
- 详情仅返回必要事件字段，不返回原始 subscriber attributes、认证配置或服务端密钥。

本机已经执行迁移 0007、0008，并回填既有已处理事件。其他环境部署时执行：

```sh
.venv/bin/python manage.py migrate billing
.venv/bin/python manage.py backfill_billing_payments
```

回填命令可重复运行，只生成报表，不调用支付/发钻接口。部署后需要重启 API 和 Celery worker。未收到的历史渠道交易不会凭空出现，需要先解决对应回调接收或历史数据导入。
