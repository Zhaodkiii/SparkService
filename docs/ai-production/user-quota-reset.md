# 用户额度列表与重置

2026-11-05。用户额度列表只包含有 reserve 或 settle 历史流水的启用账户，包含当前已恢复、退款或重置过的账户。搜索和分页使用相同过滤条件，打开列表不创建周期。

列表新增“重置额度”，具备 button:ai:production:reset 权限的管理员可选择 5 小时、7 天或两者，必须填写原因。POST /api/admin/v1/ai-production/users/{accountID}/reset/ 接收 request_key、scope 和 reason。

重置将所选活跃窗口结束时间设为当前服务端时间，历史账本及计数保留。下一次新制作开始新周期，当前规则决定上限。已有任务继续结算原窗口。账户行锁串行化与新制作的竞争，唯一请求键保证重发不影响重置后新开启的周期。

ProductionQuotaReset 记录操作者、用户、范围、原因与旧窗口快照，后台审计 action 为 production.quota.reset。本地已执行迁移 0007 并重启 API。没有实际重置账户 6 或其他业务账户。
