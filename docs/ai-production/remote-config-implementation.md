# AI 远程配置直连实施与运维

2026-11-08。本次代码已接入客户端、Django、管理后台；尚未部署生产、录入生产凭证或完成真实供应商/真机验收。

## 部署

1. 为当前环境生成独立 Fernet 主密钥，保存在部署密钥系统；通过 `AI_RUNTIME_ENCRYPTION_KEYS` 注入（逗号分隔，新主密钥放首位，保留旧密钥供解密）。不可使用 Django SECRET_KEY 替代，不可把主密钥提交仓库。备份数据库时同时安全备份解密能力。
2. `AI_RUNTIME_ALLOWED_HOSTS` 设置批准的供应商域名，默认仅 `ark.cn-beijing.volces.com`。后台不能自行增加出站域名。多环境分别部署/使用独立数据库、凭证与主密钥。
3. 运行 `python manage.py migrate`；迁移创建配置通道和权限。部署 API、Celery worker 和后台构建产物，重启后使用已有权限管理为运营人员分配 `menu:ai:runtime` 及所需按钮权限。
4. API 路由 `/api/v1/ai-runtime/`、`/api/admin/v1/ai-runtime/` 禁止代理/CDN 缓存及请求响应正文日志。应用已加 no-store 及日志省略，反向代理配置仍需部署检查。
5. 管理后台「AI 制作 → AI 服务配置」新增供应商、模型与凭证槽位；保存密钥 v1，配置四场景草稿并保存。先在凭证面板指定 v1 测试草稿，通过后激活；再测试全部场景，通过后发布。测试使用合成图片并可能计费，需要 Celery worker。
6. 发布 iOS 新版前先发布配置。验证新任务、断网恢复、401 刷新及生图；任务完成摘要仍用现有额度接口。
7. 迁移窗口结束设置 `AI_RUNTIME_REQUIRE_CAPABILITIES=true`，阻止无兼容声明的旧客户端创建新任务；随后在供应商处撤销历史包中的旧 Key。仅设置最低版本不能撤销已提取 Key。

## 轮换与恢复

新密钥以独立版本保存，不立即生效。在凭证面板选择新版本，对草稿及所有引用该槽位的历史发布逐一测试，全部通过后激活。历史任务固定模型/参数/端点，续租获取新凭证。确认正常客户端更新后在供应商控制台撤销旧 Key。紧急泄漏立即在供应商处撤销，并在本系统停用供应商、槽位或场景；已发出的直连请求无法由配置接口撤销。

凭证仅在 iOS 内存中保留，不写普通磁盘；退出账号清除并取消该运行时会话中的请求。配置租约 15 分钟，前台恢复与续作重新获取；有效期按服务端时间差与单调时钟计算。当前客户端采用保守失败关闭：刷新失败立即暂停后续调用，不继续使用剩余租约。任务检查点不包含密钥。

配置发布只影响新任务。回滚生成新发布，保留历史任务绑定。旧任务没有绑定时明确拒绝配置下发，保留本地作品，由用户结束旧任务后重建；不自动混用旧 continuation。

运行 `python manage.py prune_ai_runtime_records` 清理超过 180 天的下发、事件、测试和审计记录；发布与任务绑定保留。可加入现有运维定时任务。

## 实现边界

当前两个协议为 ark_responses_v1 / ark_images_v1，其他协议须实现客户端适配器并发版。部署仅一个 iOS 配置通道，不含随机灰度。后台列表目录尚未做服务端分页；诊断记录已分页，发布与测试列表返回最近 100 条。控制接口通过 version 防并发重复写，冲突后需刷新；发布和凭证激活支持请求键幂等。

客户端自报事件仅为诊断，不能证明上游费用。后台具备测试、记录筛选与当前页脱敏导出；尚未接外部监控告警平台或供应商账单。配置 hash 当前用于服务端一致性和客户端续租版本比较，不声称提供离线签名验证。
