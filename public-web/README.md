# TravelDiary 本地 Web

用户站端口 6028，API 代理到 2026。运行 `pnpm install` 后 `pnpm dev`，构建 `pnpm build`。

新版入口为 BookApp.vue：本机书架、模板选择、阅读单元、CSS 3D 翻页、当前页照片替换、Alpha 蒙版与四角网格映射、本机保存和跨页 JPG 导出。旧 App.vue 暂留作历史原型，不再加载。

本地模板选集由 public_experience/local_books.json 指定；只能通过局域网或 localhost 主机访问，对 app.dreamwhale.top 不开放。生产还需要显式内容发布、许可与权限流程，不能直接拿本地接口作为公开发布入口。

添加只读取元数据和封面；浏览读取当前和相邻预览，缩略图进入视口后加载；替换时才获取当前页对象与图片。用户照片不上传。当前按需投影会读取该页对象 JSON，图片本地开发经固定 OSS 存储桶 Vite 代理解决 CORS；生产仍使用直连 OSS 并配置精确 CORS。

翻页为透视旋转动画；尚无原生弯曲卷纸和跟手半程回弹。照片取景目前提供缩放和填充切换，尚未提供平移。复杂透明轮廓会拒绝替换并保留原稿。

检查：前端构建、Django check、2 项接口/权限隔离测试、真实模板 browse/projection 请求、本地 OSS 代理 HTTP 200。浏览器自动化因 Work 设置禁用未执行；实际视觉、手机手势、照片合成和离线重开仍需真机验收。只添加模板的整本不保证离线可读；照片替换的合成图已本地保存，但用于再次合成的模板原资源尚未本机持久化。
