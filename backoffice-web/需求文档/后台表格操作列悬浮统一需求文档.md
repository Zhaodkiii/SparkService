# 后台右侧悬浮操作按钮统一需求文档

## 1. 背景

管理后台中多个列表页存在“操作”按钮。当前 `/version/configs` 页面已经在表格右侧使用悬浮操作按钮，效果和交互符合预期，需要将项目内其它涉及操作按钮的列表页统一参考该页面的右侧悬浮操作按钮模式。

本需求的重点不是单纯描述“横向滚动时操作列固定”，而是要求所有涉及列表操作的页面统一使用 `/version/configs` 的右侧悬浮操作按钮方案，并抽取公共实现，避免每个页面重复写 `fixed="right"`、列宽、按钮布局等代码。

本需求文档只描述需要改动的范围和设计，不直接改动业务代码。

## 2. 当前 `/version/configs` 页面右侧悬浮操作按钮参考实现

页面路径：

- 路由：`backoffice-web/src/router/routes.ts:27`
- 页面组件：`backoffice-web/src/views/VersionConfigsView.vue`

关键代码位置：

- `backoffice-web/src/views/VersionConfigsView.vue:18`
  - `<a-table ... :scroll="{ x: 1500 }">`
  - 表格提供横向滚动容器，用于支撑右侧悬浮操作区域。
- `backoffice-web/src/views/VersionConfigsView.vue:43`
  - `<a-table-column title="操作" key="actions" width="150" fixed="right">`
  - `fixed="right"` 是右侧悬浮操作按钮的核心配置。
- `backoffice-web/src/views/VersionConfigsView.vue:44-49`
  - 操作列插槽内通过 `<a-space>` 放置“编辑”“停用”按钮。

结论：当前页面的参考实现是 Ant Design Vue Table 的右侧固定列能力：表格设置 `scroll.x`，操作按钮所在列设置 `fixed="right"`。后续统一方案要以 `VersionConfigsView.vue:41-49` 的按钮布局和右侧悬浮方式为准。

## 3. 统一目标

1. 所有涉及列表操作按钮的页面，统一使用右侧悬浮操作按钮。
2. 右侧悬浮操作按钮以 `VersionConfigsView.vue:41-49` 为参考实现。
3. 悬浮操作按钮实现方式统一，不能在每个页面重复维护相同的列配置、列宽和按钮容器结构。
4. 新增页面只要存在列表操作按钮，必须使用统一的右侧悬浮操作按钮组件或封装。
5. 公共封装处需要增加注释，明确说明：以后新增带操作按钮的列表页也必须使用该右侧悬浮组件/封装。

## 4. 建议设计

新增一个公共组件，用于统一承载“右侧悬浮操作按钮”：

- 建议路径：`backoffice-web/src/components/table/FloatingActionColumn.vue`

建议职责：

- 内部封装与 `VersionConfigsView.vue:41-49` 一致的 `<a-table-column title="操作" fixed="right">` 右侧悬浮操作列。
- 提供 `width` 参数，默认值建议 `140`。
- 统一使用 `<a-space>` 或统一的按钮容器承载操作按钮。
- 透传默认插槽给业务页面放置具体按钮。
- 在组件顶部增加注释：新增带列表操作按钮的页面必须使用该组件，避免重复写右侧悬浮配置。

建议用法示例：

```vue
<FloatingActionColumn :width="150">
  <template #default="{ record }">
    <a-button v-if="canUpdate" size="small" @click="openEdit(record)">编辑</a-button>
    <a-button v-if="canUpdate && record.is_active" size="small" danger @click="onDisable(record.id)">停用</a-button>
  </template>
</FloatingActionColumn>
```

表格层要求：

- 使用右侧悬浮操作按钮的表格必须配置 `:scroll="{ x: number }"`，保证右侧悬浮区域正常生效。
- 没有横向滚动宽度的页面，也需要统一补充合理 `scroll.x`，避免右侧悬浮操作按钮不生效。
- 操作列宽度由公共组件参数维护，业务页只传特殊宽度。

## 6. 预期改动范围

1. 新增公共组件 `FloatingActionColumn.vue`。
2. 将上述所有列表操作按钮替换为公共右侧悬浮操作按钮组件。
3. 对缺少 `:scroll="{ x: ... }"` 的表格补充合理横向滚动宽度，保证右侧悬浮操作按钮生效。
4. 保留各页面现有权限判断、按钮文案、点击事件和业务逻辑。
5. 不改接口、不改后端、不改路由含义。

## 7. 注释要求

公共组件内必须增加类似注释：

```ts
// 新增带列表操作按钮的后台页面必须使用 FloatingActionColumn，
// 统一参考 VersionConfigsView 的右侧悬浮操作按钮，避免各页面重复维护 fixed/right/width 布局。
```

业务页面不建议重复写大段说明，只在公共组件集中说明规则。

## 8. 验收标准

1. `/version/configs` 仍保持当前右侧悬浮操作按钮效果。
2. 第 5 节列出的所有列表操作按钮均统一参考 `/version/configs`，并使用公共封装。
3. 所有带列表操作按钮的表格均具备可生效的 `scroll.x`。
4. 操作按钮的权限控制、禁用状态、弹窗、删除/编辑/查看等行为保持不变。
5. 新增公共组件内有明确注释，提示后续新增页面必须复用右侧悬浮操作按钮。
6. 前端类型检查和构建通过。
