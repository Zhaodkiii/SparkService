# 患者工作台最新 Plain Text UI 原型

> 原型状态：需求确认阶段  
> 更新时间：2026-09-03  
> 说明：本原型只描述患者优先的医生工作台，不包含业务代码实现。

## 0. 参考样式 v2

本版按参考图重新组织视觉原型：

- 深色左侧医院导航与医生身份区。
- 左侧患者列表，中间患者工作台，右侧会话详情/辅助信息区域。
- 浅灰页面背景、白色圆角卡片、细边框和蓝紫主色。
- 患者工作台首屏不再是成员对话，而是患者身份、基础资料和患者会话列表。
- 已打开会话预览图：[患者工作台最新预览图-v2.svg](./患者工作台最新预览图-v2.svg)
- 未打开会话详情预览图：[患者工作台未打开会话详情预览图.svg](./患者工作台未打开会话详情预览图.svg)

未打开会话详情时，右侧区域展示患者辅助信息：AI 总结、风险评估、患者画像和会话时间线；不会展示消息流、输入框或接管按钮。

## 1. 页面定位

医生进入工作台后，第一层是患者，不是成员对话。

页面默认展示：

- 当前患者身份与服务状态。
- 患者基础资料，只读。
- 当前医生有权查看的全部院内会话。
- AI 总结。
- 风险评估。

点击具体会话后，右侧划出会话抽屉；首次进入患者工作台时不自动打开任何会话。

## 3. 交互与状态约束

| 场景 | 结果 |
| --- | --- |
| 首次进入患者 | 先显示患者资料和会话列表，不自动打开会话 |
| 有缓存 | 先显示缓存，后台刷新资料、会话和风险 |
| 无缓存 | 各模块独立显示加载态 |
| 会话点击 | 右侧打开对应 Thread 的会话抽屉 |
| 医生接管 | 患者消息进入原会话，AI 不自动回复 |
| 取消接管 | 后续患者消息允许 AI 回复 |
| 已结束会话 | 历史可读，输入禁用，新建咨询创建新 Thread |
| AI 总结 | 医生主动生成/刷新，正文只读，可标记“已了解” |
| 风险评估 | 独立复用现有风险工具，不在患者工作台直接改级 |

## 4. 本原型明确不展示

- 患者完整手机号和证件号。
- 患者完整病史、报告正文和长期医疗记录全文。
- 医生备注、患者待办和科室共享待办。
- AI 总结编辑入口。
- 患者基础资料编辑入口。
- 患者工作台直接调整风险等级入口。
- 医院全部患者或当前医生未授权的患者/会话。
