## 1. 默认状态

患者列表保持原来的独立一列；当前服务智能体是患者业务区域的公共头部，位于患者列表和患者信息之上。

患者信息与工作台主区的纵向顺序为：

~~~text
基础资料（只读）
AI 总结（系统生成）
风险评估（现有风险工具）
患者会话（当前医生有权查看）
~~~

## 6. 保存反馈与冲突

### 6.1 保存成功

~~~text
┌──────────────────────────────────────────────────────────────┐
│ ✓ 智能体资料已保存                                           │
│                                      [继续编辑] [完成]       │
└──────────────────────────────────────────────────────────────┘
~~~

完成后关闭弹窗，头部立即展示服务端返回的新数据。

### 6.2 版本冲突

~~~text
┌──────────────────────────────────────────────────────────────┐
│ 智能体资料已在其他页面或设备更新。                           │
│ 加载最新内容将覆盖当前尚未保存的输入。                       │
│                                   [取消] [加载最新内容]      │
└──────────────────────────────────────────────────────────────┘
~~~

不得自动覆盖当前输入，不得自动重试保存。

### 6.3 未保存关闭

~~~text
┌──────────────────────────────────────────────────────────────┐
│ 尚有未保存修改，确定关闭吗？                                 │
│                                   [继续编辑] [放弃修改]      │
└──────────────────────────────────────────────────────────────┘
~~~

## 7. 响应式收缩规则

~~~text
宽屏：患者身份在上，智能体完整信息条在下，编辑按钮靠右。
中屏：智能体简介省略为一行，知识库数量与编辑按钮换到第二行。
窄屏：医生、职称、科室允许换行；简介隐藏；编辑按钮保持可见。
极窄：患者身份与智能体信息仍保持两个区块，不混成同一标题。
~~~

## 8. 交互约束

| 操作 | 结果 |
| --- | --- |
| 切换患者 | 智能体信息不闪烁、不重复请求 |
| 点击编辑 | 打开弹窗，不离开患者工作台 |
| 保存成功 | 更新头部，不刷新整页 |
| 提交审核 | 更新状态，表单按现有规则只读 |
| 点击遮罩或 Escape | 无修改直接关闭；有修改先确认 |
| 打开会话抽屉 | 抽屉展示该 Thread 实际绑定的智能体；头部仍展示当前医生智能体 |
| 智能体接口失败 | 只影响信息条，不影响患者资料与在线会话 |
